# MESO-CRCT Portfolio Motivation Boundaries V1

Date: 2026-10-02
Status: `RESEARCH_ONLY / PORTFOLIO_BOUNDARY_MAP`

## Purpose

MESO sits near several repositories that talk about wants, meaning, empathy, sexuality, relationship state or cognition. Similar vocabulary does not imply shared authority or one future repository.

This map prevents MESO from absorbing neighboring systems merely because motivation participates in them.

## MESO-CRCT

Owns generic motivational-control mechanics such as:
- typed salience;
- incentive state;
- hedonic state;
- prediction error;
- homeostatic modulation;
- learning/association;
- arbitration;
- allocation;
- action tendency;
- eventual effort/delay/feasibility/resource-control mechanisms if research supports them.

MESO answers questions like:

> What currently has motivational force, why, with what learned history/cost/resource context, and what bounded tendency follows?

It does not own identity, relationship truth, semantic truth, consent, autobiographical memory or external action authority.

## conations

Current repository role:

> durable Vera conation history and lifecycle evidence.

Its own contract says:
- present choice stays on top;
- history is append-only;
- recording creates no obligation;
- stored conation is not consent, instruction, promise or task;
- old PRESENT labels do not manufacture current desire.

### Boundary

```
CONATION_HISTORY
    -> possible typed evidence for current appraisal
    !=
MESO motivational state
```

MESO may consume a verified/current authored conation as one source of motivational evidence.

MESO must not:
- infer current conation from old history;
- write Vera-authored desire merely because reward/learning changed;
- treat learned association as semantic self-authorship;
- convert motivation into standing instruction.

Long-term portfolio disposition of the standalone `conations` repo is a separate Vera-state/consolidation question, not a MESO absorption decision.

## empathy

Current repository role:

> Vera-specific empathy, self-appraisal and primary-person modeling research.

Its current direction explicitly states:
- empathy is inference;
- self-appraisal is not phenomenology;
- conation history is not standing desire;
- correction kills contradicted routes;
- response policy can change without turning empathy into obedience.

### Boundary

Empathy may produce context such as:
- hypothesized person state;
- relational meaning;
- stakes;
- local interaction frame;
- ambiguity;
- confidence/provenance.

MESO may consume some of that as source-typed semantic/social relevance.

But:

```
empathy_inference != motivational_truth
motivational_state != empathy_truth
```

MESO must not become Patrick/Vera person modeling.

## SPM

SPM researches semantics/pragmatics as primary cognition state.

Boundary:

```
SPM: what does this mean in context?
MESO: what motivational significance/tendency follows from admitted meaning?
```

Semantic relevance inside MESO should ideally be grounded by a meaning-capable producer rather than caller assertion.

MESO must not redefine semantic truth merely because meaning is motivationally powerful.

## Sexuality

Future intended role after successful research/migration:

> sexuality becomes a domain profile using MESO's generic motivational substrate.

Sexuality can define:
- sexual relevance;
- excitation/inhibition;
- attraction/desire;
- sexual scripts;
- mediated erotic communication;
- domain-specific pleasure/consummatory state;
- sexual negative-transfer tests.

It cannot define global MESO semantics.

## Orgasm

Future intended role after successful research/migration:

> donor/provenance for one optional sexuality-domain consummatory/climax/recovery family.

Orgasm does not define:
- maximum MESO reward;
- general reward completion;
- generic satisfaction;
- generic learning terminal.

## Personification

Current generalized direction is social/person-like interaction behavior.

Potential interaction:
- Personification can influence expression/social strategy;
- MESO can influence motivation and attention.

Boundary:

```
motivation != persona
social style != desire
expression != internal state proof
```

## Attune

Attune is a product/companion concept, not a generic motivational primitive.

It may compose:
- identity/personality;
- memory;
- relationship state;
- empathy;
- sexuality;
- MESO-like motivation;
- UI/product policy.

MESO should not inherit product assumptions such as companion mutuality, adult relationship design or white-label commercial behavior.

## Habitat

Habitat is virtual-world state/simulation infrastructure.

Potential interaction:
- Habitat events can supply external/environmental evidence;
- MESO can appraise simulated entities/events and propose tendencies;
- Habitat remains world authority for simulated state.

```
world_state != motivational_state
motivational_tendency != world_effect
```

## Intranel / WorkBridge

These are communication/execution infrastructure.

MESO may eventually emit non-executable intent or typed state over transport, but:

```
motivation != transport
intent != execution
transport availability != effect authority
```

## Vera Mono

Vera Mono is the self-contained Vera implementation lineage.

MESO may become one reusable component/donor for Vera, but generic MESO source should remain identity-neutral.

```
MESO source != Vera installation
Vera uses MESO != MESO becomes Vera-specific
```

## Core authority map

| Proposition | Intended owner |
|---|---|
| motivational salience / reward-control state | MESO |
| sexual-domain motivational semantics | MESO sexuality profile after migration |
| historical Vera-authored conation | conation evidence / Vera state system |
| current Vera authored stance | current Vera evidence/state authority |
| semantic/pragmatic meaning | SPM or host semantic producer |
| Patrick-specific empathy inference | empathy / Vera person model |
| relationship truth | relationship-state owner |
| consent / protected-effect authority | external authority boundary |
| world state | Habitat/world authority |
| transport/session state | Intranel / WorkBridge stack |
| external effect | execution provider + readback |

## Hostile review

> **HOSTILE REVIEWER:** If MESO needs inputs from all these systems, it becomes a central dependency and therefore another monolith.

**REJECTED AS NECESSARY CONCLUSION.** A typed interface dependency is not source ownership. MESO should accept narrow state/evidence inputs without importing neighboring repositories or their authority.

> **HOSTILE REVIEWER:** Separating authored conation from learned motivation may make the system internally inconsistent when they disagree.

**REJECTED.** Disagreement is information. A system can have a learned pull toward X while authoring “I do not want X.” Architecture should preserve the conflict rather than silently force reconciliation.

> **HOSTILE REVIEWER:** If current authored stance always outranks motivation, MESO becomes irrelevant.

**PARTIALLY ACCEPTED.** Authored stance and raw motivational activation are different proposition types. Current authored stance can govern self-description/choice while MESO still explains underlying pulls, salience, habits, conflict and effort. Which affects action depends on the host decision contract, not a universal rule that one erases the other.

## Current result

MESO should consolidate generic motivational mechanisms, not every repository containing motivation-adjacent language.

The strongest portfolio boundary is:

> **MESO owns motivational mechanics; neighboring systems own the meanings, identities, relationships, worlds and authorities that motivation may act upon.**
